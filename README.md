# Data_Science
### 📊 Superstore_USA_Analysis
1) This project utilizes a Superstore USA Excel dataset containing three distinct sheets: Orders, Returns, and Users.
2) The dataset provides a comprehensive view of retail operations, including order transactions, customer details, and return records.
3) Extensive data cleaning was performed to handle missing values, incorrect formats, and duplicate records.
4) Cleaned datasets and visual EDA reports were generated and organized into structured folders for easy accessibility.
5) The prepared dataset is ideal for uncovering key sales trends, customer behavior patterns, and product/category-level insights.
